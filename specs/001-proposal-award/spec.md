# 001 Proposal -> Review -> Award

## Flow
Create Proposal -> edit team/budget/outputs/documents -> validate -> submit -> review -> approve/reject -> issue Award -> create PLANNING Project.

## Rules
- 仅 DRAFT/REVISION_REQUIRED 可编辑。
- 提交至少要求 title/objectives/endDate/budget/member。
- 申请值不可被 Award 覆盖。
- 一个 Proposal 最多一个 Award，一个 Award 最多一个 Project。
